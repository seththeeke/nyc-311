# web-app

React + Vite SPA for NYC 311. See `CLAUDE.md` §5.1 for directory structure and
conventions, and `docs/1-data-ingestion.md` for the ingestion slice this
dashboard surfaces.

| Command | Purpose |
|---|---|
| `npm run dev` | Local dev server |
| `npm run build` | Typecheck + production bundle |
| `npm run lint` | ESLint |
| `npm run test` | Vitest |
| `npm run test:coverage` | Vitest with coverage (90% gate, per file) |
